Cybersecurity Lab Setup – Kali Linux Virtual Lab

📌 Project Overview

This project focuses on setting up a virtual cybersecurity laboratory using Kali Linux and Oracle VirtualBox. The lab provides a controlled environment for learning Linux system administration, network configuration, and basic cybersecurity practices.

The virtual machine runs on a Windows 11 host system and uses a dedicated NAT Network for network communication.

🎯 Project Goals

The main objectives of this project are:

- Install and configure Oracle VirtualBox on Windows 11.
- Prepare and import the Kali Linux virtual machine.
- Create a dedicated NAT Network.
- Configure network settings in Kali Linux.
- Set up a consistent IPv4 address.
- Verify network connectivity.
- Establish a functional virtual cybersecurity lab environment.

⚙️ Implementation Process

Step 1 – Preparing the Environment

- Prepared the Windows 11 host system.
- Installed Oracle VirtualBox.
- Downloaded and extracted the Kali Linux virtual machine files.

Step 2 – Kali Linux Installation

- Imported the Kali Linux virtual machine into VirtualBox.
- Configured the virtual machine.
- Started Kali Linux and verified access to the operating system.

Step 3 – Virtual Network Configuration

- Created a dedicated NAT Network in VirtualBox.
- Configured the virtual network settings.
- Connected the Kali Linux virtual machine to the NAT Network.

Step 4 – Network Setup in Kali Linux

- Configured network settings within Kali Linux.
- Checked the network interface configuration.
- Set up a consistent IPv4 address.

Step 5 – Connectivity Checks

- Verified the assigned IP address.
- Tested network connectivity.
- Checked communication between the virtual machine and the network.
